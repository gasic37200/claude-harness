# 결정 기록

정해진 것과 그 근거를 쌓는 곳입니다. 항목은 고쳐 쓰지 않습니다. 결정이 바뀌면 새 항목을 아래에 추가하고, 이전 항목의 「상태」만 `대체됨 → D-새번호`로 바꿉니다.

| 칸 | 쓰는 법 |
|---|---|
| 제목 | 「결정되는 속성」으로 짓기 (예: `결제 결과 불명일 때 주문 상태`) |
| 누가 | `나` (사람이 정함) · `AI` (AI가 제안, 사람이 안 봄) · `측정` (실험 · 수치로 정함) |
| 상태 | `유효` · `대체됨 → D-NNN` · `철회` |
| 근거 | 왜 그렇게 정했나. 커밋 · PR · 이슈 · 측정값이 있으면 같이 |
